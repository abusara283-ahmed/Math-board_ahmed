# لوح الرياضيات — تطبيق أندرويد

سبورة رياضيات للمعلم: قلم وتمييز وأشكال هندسية ومسطرة ومنقلة وشبكات المجسمات وقرعة الطلاب، مع فتح ملفات PDF والصور والكتابة عليها.

## تحميل التطبيق
آخر نسخة دائماً في صفحة **Releases** (الإصدارات) على يمين صفحة المستودع، والملف اسمه `math-board.apk`.

## كيف تُبنى النسخة
كل تعديل يُرفع إلى الفرع `main` يبني ملف APK جديداً تلقائياً (تبويب **Actions**) وينشره في **Releases**.
النسخ كلها موقّعة بنفس المفتاح (`android/app/mathboard.keystore`)، لذلك تُثبَّت النسخة الجديدة فوق القديمة دون حذف السبورات المحفوظة.

## محتوى المستودع
- `www/index.html` — التطبيق نفسه (صفحة واحدة).
- `www/vendor/` — pdf.js 3.11.174 و jsPDF 2.5.1 والخطوط، محفوظة داخل التطبيق ليعمل بدون إنترنت.
- `android/` — مشروع أندرويد (Capacitor 7).
- `.github/workflows/android.yml` — البناء التلقائي.

## الحفظ التلقائي
السبورات (الصفحات والرسومات) تُحفظ تلقائياً على الجهاز كل بضع ثوانٍ وعند الخروج من التطبيق، وتعود عند فتحه.
ملفات PDF والصور المفتوحة لا تُحفظ تلقائياً (لحجمها)؛ صدّر الشرح بزر «تصدير» إذا أردت الاحتفاظ به.

## التطوير على الكمبيوتر
```
npm ci
npx cap sync android
cd android && ./gradlew assembleRelease
```
